## 为什么需要它 / Why it helps

读完一本书、划了重点、听了总结，还是可能不知道怎样把知识用进自己的工作、学习或生活里。  
You can finish a book, highlight passages, and listen to a summary—yet still be unsure how to use the ideas in your work, study, or daily life.

**Book-to-Project** 帮你从书或长文档里找出与当前目标相关的观点，把它变成一件可编辑、可使用的成果，再设计一个真实、低成本的检查方式。  
**Book-to-Project** finds ideas relevant to your current goal, turns one into an editable artifact, and defines a real, low-cost way to check it.

**书里的观点 → 你的问题 → 一个小成果 → 实际验证 → 下一步调整**  
**Source idea → your problem → a small artifact → a real check → the next adjustment**

<a id="what-it-creates"></a>
## 它会产出什么 / What it creates

| 环节 / Part | 你会得到什么 / What you get |
| --- | --- |
| 书中依据 / Source evidence | 相关观点、所在章节或位置、适用条件和注意事项 / Relevant ideas, their source locations, when they apply, and cautions |
| 现实问题 / Your problem | 谁遇到什么问题、目前发生什么，以及哪些信息仍是假设 / Who faces what problem, what happens now, and what is still an assumption |
| 可用成果 / Usable artifact | 一张学习卡、一份决策备忘录、页面草稿、流程原型或小实验 / A learning card, decision memo, page draft, workflow prototype, or small experiment |
| 真实检查 / Real check | 一个低成本的测试方式；尚未执行的结果会标成“待验证” / A low-cost test; results are marked “not yet tested” until it actually runs |

<a id="workflow"></a>
## 工作流程 / Workflow

1. **找到相关观点 / Find relevant ideas**  
   记录来源位置、适用条件和可能失效的情况，不把目录当成观点证据。  
   Record the source location, when an idea applies, and where it may fail. A table of contents is not evidence for a claim.

2. **界定现实问题 / Define the real problem**  
   分清观察到的事实、你提供的信息和仍需验证的假设。  
   Separate observed facts, user-provided context, and assumptions that still need checking.

3. **做一个小而有用的成果 / Make one small, useful artifact**  
   选择可以开始使用的具体成果；范围太大时先做一小块，不停留在宏大路线图。  
   Choose something concrete that can be used. If the goal is broad, make a small first slice instead of stopping at a grand roadmap.

4. **让每个决定有依据 / Keep decisions traceable**  
   记录“书中观点 → 项目判断 → 成果设计 → 检查方式”。  
   Track “source idea → project inference → artifact decision → test.”

5. **实际检查并调整 / Test and revise**  
   记录真正执行了什么、看到了什么、下一步怎么改；没有实际结果就明确写“待验证”。  
   Record what actually ran, what was observed, and what to change next. If there is no real result yet, say “not yet tested.”

<a id="example"></a>
## 使用案例 / Example

**问题 / Problem**

> 晚饭后我常常拿起手机，很难开始读书。  
> After dinner, I often pick up my phone and struggle to start reading.

**一个项目草案 / A project proposal**

- **书中想法 / Book idea:** 选择一个与“让想做的行为更容易开始”有关的观点，并回到原文核对适用条件。这里是对观点的转述，不是书中原句。  
  Pick a source idea about making a desired action easier to start, then check its conditions in the book. This is a paraphrase, not a direct quote.
- **成果 / Artifact:** 把书放在容易看见的地方；晚饭收拾完后先读一页；用一张小记录表写下当天是否开始，以及卡在哪里。  
  Place the book where it is easy to see. After clearing dinner, read one page and note whether you started and what got in the way.
- **检查 / Check:** 作为一个小范围的项目设计，在两周后回看记录，找出哪些安排容易重复、哪些阻碍还在。  
  As a scoped project test, review the notes after two weeks to see which parts were easy to repeat and which obstacles remained.

**状态 / Status:** 这是一个待执行的项目草案，不是书里规定的时间表，也没有声称习惯已经养成。  
This is a proposed project, not a schedule prescribed by the book. It has not been tested, and it does not claim that a habit has formed.

<a id="how-to-use"></a>
## 如何使用 / How to use

提供一本书、文档或节选，并说明你现在想解决的问题、时间和工具限制，以及希望做出什么成果。  
Provide a book, document, or excerpt, then describe the problem you want to solve, your time and tool constraints, and the artifact you want to make.

~~~text
Use $book-to-project with this book and my current goal.
Help me make one small artifact I can actually use.
Show which ideas come from the source, what is my project decision,
and how I can test the result.

请用 $book-to-project，把这本书和我当前的目标连起来。
帮我做出一个可以实际使用的小成果。
标清哪些来自原文，哪些是项目设计，并说明怎么检查结果。
~~~

支持 PDF、EPUB、DOCX、Markdown、TXT 和用户提供的节选。文本提取脚本适用于文本为主的文件；扫描页、复杂表格、图片和代码需要额外检查。  
Supported sources include PDF, EPUB, DOCX, Markdown, TXT, and supplied excerpts. The text extraction script works best with text-based files; scanned pages, complex tables, images, and code need additional checks.

<a id="limits"></a>
## 限制与隐私 / Limits & privacy

- 生成了草稿，不等于已经验证有效。  
  A generated draft is not proof that it works.
- 不编造书中引文、页码、用户反馈、测试结果或已实现功能。  
  Do not invent quotes, page numbers, user feedback, test results, or implemented features.
- EPUB 定位可能是文件内部位置，不一定对应纸书页码；扫描文件和复杂版面需检查提取准确性。  
  EPUB locators may not match print page numbers. Check extraction fidelity for scans and complex layouts.
- 只处理你有权使用的材料；不要把整本书、提取出的长篇原文、私人记录或凭据提交到公开仓库。  
  Use only material you have the right to use. Do not commit a full book, long extracted passages, private records, or credentials to a public repository.
- 本仓库当前没有指定开源许可证；公开可见不等于已授权复制、修改或再发布。  
  This repository currently has no specified open-source license. Public visibility does not grant permission to copy, modify, or redistribute it.
